# Corpse Party 2: Dead Patient · iOS

A native arm64 iPhone port of *Corpse Party 2: Dead Patient*, made by recompiling the original game program rather than remaking or emulating it. The game's own logic runs unchanged; its Windows graphics, audio and animation plugins are reimplemented natively and checked bit for bit against the originals. Work in progress. This repository holds the port's own code only; no game files are included or distributed.
